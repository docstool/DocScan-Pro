# DocScan Premium

A polished browser-first document scanner and PDF workspace.

## Included
- Camera scanner with front/rear camera switching
- Image and PDF import
- Multi-page document workspace
- Drag-and-drop page ordering
- Duplicate/delete/rotate pages
- Four-corner crop workflow
- Document enhancement and filters
- Brightness and contrast controls
- Annotation and signature drawing
- Add text
- PDF creation/merge
- Page extraction
- OCR, loaded on demand
- Image compression with targets down to below 30 KB
- PDF compression
- Responsive premium UI
- Local browser-first processing

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the repository root and publish the `main` branch `/ (root)` with GitHub Pages.

## Notes
PDF.js, PDF-Lib and Tesseract.js are lazy-loaded from public CDNs only when their features are used. A password-protected PDF requiring a password is not supported in this static browser-only edition.


## Premium graphics
Includes lightweight original SVG artwork for the scanner hero and PDF Studio banner. These are local assets and add no external image-hosting dependency.


## V5 professional viewer
- Live document preview in PDF Studio
- Zoom in/out and page navigation
- Fit-to-page and actual-size controls
- Full-screen main preview
- Preview remains synchronized with the current page
