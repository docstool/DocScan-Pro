# DocScan Pro 2

Advanced browser document scanner and PDF studio for GitHub Pages.

Includes:
- Camera scanning
- Multi-page image/PDF import
- PDF page thumbnails
- Merge imported documents into one document
- Reorder by page selection/export
- Delete and duplicate pages
- Rotate pages
- Split/export selected pages
- PDF export
- JPG/PNG export
- OCR text recognition
- Annotation and signature drawing
- Perspective crop workflow
- Edge detection hooks
- Document filters/enhancement
- Target-size image compression, including a <30 KB target
- PDF compression via image-quality control
- Mobile-friendly interface

Important: "below 30 KB" is a target, not a guarantee. Complex documents may become unreadable or may not be able to reach that size. PDF features are performed client-side where supported. External libraries are loaded from CDNs, so the site needs an internet connection.
