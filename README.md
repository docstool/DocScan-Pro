# PhotoEdit Pro

Free browser-only photo editor.

Features: adjustments, filters, image resizing/presets, rotate, flip, border, vignette, text, undo/redo and PNG download.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. Open the generated `github.io` address.

No backend is required; photos are processed in the visitor's browser.
